# SNA Technologies Website

Wolfiz-inspired premium technology agency website built with React + Vite + Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Content editing

Most business content is controlled from:

`src/data/siteConfig.js`

You can change:
- Company name, email, phone and location
- Navigation
- Hero headline and rotating words
- About content
- Services
- Process
- Industries
- Projects
- Testimonials
- Contact CTA
- Social links
- Footer

The visual components do not need to be edited for normal content changes.

## Next customization

Replace placeholder project information and contact details in `siteConfig.js`, then add the real SNA logo/brand assets when available.
